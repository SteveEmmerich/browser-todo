# Browser Todo

Small React pilot for the Engineering Standards and Hlidskalf workflow. The human requested a simple React todo app with browser localStorage and no server side.

The initial checkout contains the proposed journey contract and task draft only. Application implementation, the actual GitHub task/assignment, protected CI, and human acceptance are pending. No running app or successful end-to-end workflow is implied.

Planned stack: React, TypeScript, Vite, and Node/npm, using the technologies already approved for this initiative. Todos stay in localStorage for the current browser origin; there is no cross-device synchronization or server component.

See [journey criteria](docs/journeys.md) and [task draft](docs/task-draft.md). Engineering Standards 0.1.0 is pinned independently in standards.lock.json; its installed skills are under .agents/skills.
